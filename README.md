# PELICAN COAST · 鹈鹕海岸骑行

一个使用 Three.js 的交互式 3D 海岸骑行页面，无构建步骤。Three.js 随仓库提供，字体加载失败时自动使用系统字体。

## 操作

- ↑ / ↓：加速、减速
- ← / →：三车道变道
- 空格：跳跃
- W：按住抬前轮
- C：循环切换 5 种镜头
- 手机：使用页面底部触屏按钮
- 8 秒未操作后自动巡航，也可点击巡航按钮
- 点击声音按钮开启 Web Audio 实时合成音效

## 功能

头盔、墨镜、红围巾鹈鹕，自行车轮与踏板动画，Verlet 围巾物理，海浪与昼夜循环，自动追鱼，14 个本地存储成就，5 个镜头，帧率自适应分辨率。

昼夜周期为 180 秒。成就跨刷新保存，里程与渔获为本次会话数据。需要支持 WebGL 的现代浏览器。

## 本地预览

在此目录运行 `python3 -m http.server 4173`，访问 `http://localhost:4173`。不要通过 file:// 直接打开模块脚本。
